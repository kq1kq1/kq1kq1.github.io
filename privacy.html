プライバシーポリシー

制定日：2026年10月11日

1. このアプリについて

Hermes は、管理者（GitHub: kq1kq1）が個人で利用する AI アシスタントです。利用者は管理者本人のみで、第三者への提供は行っていません。

2. 利用する Google のデータ

  • Gmail：メールの閲覧のみ（送信・削除・変更は行いません）
  • Google カレンダー：予定の閲覧、本人の指示による予定の追加・変更
  • Google ドライブ・スプレッドシート：ファイルの閲覧のみ

3. データの取り扱い

  • 取得したデータは、管理者本人のパソコン内でのみ処理します。
  • データを第三者に販売・提供・共有することはありません。
  • 広告や、管理者本人を手伝う以外の目的には利用しません。
  • Google の認証情報（トークン）は、管理者本人のパソコン内にのみ保存します。

4. Google API サービスのユーザーデータに関するポリシーへの準拠

Hermes による Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。

5. アクセスの取り消し

Google アカウントのサードパーティ製のアプリとサービスから、いつでも Hermes のアクセスを取り消せます。

6. お問い合わせ

GitHub（kq1kq1）までご連絡ください。
